# Gazette News — News & WooCommerce WordPress Theme

Original WordPress theme in the style of a classic newspaper / magazine site, with WooCommerce shop support.

This is **not** the commercial tagDiv Newspaper theme. It is a custom, GPL-licensed theme with a similar news layout: breaking ticker, featured mosaic, category modules, sidebar widgets, and a store section.

## Install

1. Copy the `gazettenews` folder into `wp-content/themes/`.
2. In **Appearance → Themes**, activate **Gazette News**.
3. (Optional) Install and activate **WooCommerce** for the shop.
4. **Settings → Reading**: you can keep “Your latest posts” as the homepage. The theme builds a magazine layout automatically.
5. Or create a page, assign template **Magazine Homepage**, and set it as the front page.

## Homepage sections (tagDiv alternative)

**tagDiv Composer is not included and is not compatible.** It is a paid Newspaper-theme plugin.

Manage the homepage like Newspaper modules:

1. **Appearance → Homepage Sections**
2. Set **Section name**, **Place** (Left / Right / Full width), category, layout, **post count**
3. Add ads in any column (image URL + link, or HTML)
4. Drag to reorder. Buttons: Add full-width ad, Add right ad, Add left/right posts
5. **Reset to India-news layout** restores big featured left + list right + ad slots

Block editor also has **Gazette: Featured mosaic**, **Gazette: Posts module**, and **Gazette: Shop**.

Posts show **comment count** and **view count**. Single posts include Facebook, Twitter, WhatsApp, Telegram, LinkedIn, Email, and Copy link sharing.

## Header (India News style)

**Customize → Gazette News → Colors & Branding / Header**

- Logo line 1 (red) + line 2 (black box), or a custom logo
- Green menu color, red accent / BREAKING NEWS
- Header 728×90 advertisement image, URL, or HTML

## Customize

**Appearance → Customize → Gazette News**

- Accent color (default `#4db2ec`, Newspaper-style cyan)
- Header tagline
- Breaking news label and ticker count
- Customizer module defaults (used until Homepage Sections is saved)
- Social URLs
- Footer copyright

## Menus

- **Primary** — main dark bar
- **Top Bar** — small links above the logo
- **Footer**
- **Mobile** — optional; primary is used on small screens

## Widgets

- Main Sidebar, Shop Sidebar, Header Advertisement (728×90), Home After Featured
- Footer 1–4
- Custom widgets: Popular Posts, Category Posts, Advertisement, Newsletter

## WooCommerce

Theme support includes product gallery zoom/slider/lightbox, a 3-column shop grid, shop sidebar, header cart count, and a homepage product module.

## Suggested content

Create categories such as Politics, Business, Tech, Sports, World. Write posts with featured images. Stick 1–5 posts to fill the mosaic. Add a logo in **Customizer → Site Identity**.
